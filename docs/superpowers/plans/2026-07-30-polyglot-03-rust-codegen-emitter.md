# Polyglot Port — Sub-project 3: Rust Codegen Emitter — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Teach `tools/codegen/fsm_codegen.py` to emit Rust, create the `rust/` Cargo workspace with
exactly one crate (`ems-fsm`), and extend the FSM sync check to all three languages.

**Architecture:** The generator already walks `schemas/fsm/*.fsm.yaml` and emits Java and C++. A
Rust emitter joins them behind a `--rust-only` flag, writing to `rust/ems-fsm/src/generated/`. The
generated Rust encodes states as an enum and transitions as an exhaustive `match`, so an
unhandled transition is a compile error rather than a runtime default — that is the property the
port exists to demonstrate, and it is exactly what the Java and C++ emitters cannot give.

**Tech Stack:** Python 3 (the generator), Rust 2021 edition, Cargo workspace.

**Depends on:** sub-project 1.

## Global Constraints

- `#![forbid(unsafe_code)]` at the crate root. No exceptions in this sub-project.
- `clippy::pedantic` and `clippy::nursery` with `-D warnings`.
- Generated files carry a "do not edit" header naming the source YAML — the sync check enforces it,
  but a human who opens the file should be told before they waste ten minutes.
- **No empty module stubs.** `rust/` gets exactly one crate in this sub-project. A crate directory
  appears when it has behaviour and tests. This is the direct lesson of the `cpp/` tree.
- The emitter must not reorder or reformat the Java/C++ output. Run the sync check before and after
  to prove it.

### Task 2: The Rust emitter

**Files:**
- Modify: `tools/codegen/fsm_codegen.py`
- Modify: `tools/codegen/test_fsm_codegen_rust.py`

**Interfaces:**
- Produces: `emit_rust(fsm: dict, out_dir: pathlib.Path) -> list[pathlib.Path]`, and
  `--rust-only` on the CLI.

Target output shape for `order.fsm.yaml`:

```rust
// @generated by tools/codegen/fsm_codegen.py from schemas/fsm/order.fsm.yaml
// Do not edit. Run `python3 tools/codegen/fsm_codegen.py --rust-only` to regenerate.

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum OrderState {
    New,
    Accepted,
    // ...
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum OrderEvent {
    Accept,
    Reject,
    // ...
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct IllegalTransition {
    pub from: OrderState,
    pub event: OrderEvent,
}

impl OrderState {
    /// Exhaustive: adding a state or event to the schema makes this fail to
    /// compile until the new arm is generated. That is the point.
    pub fn apply(self, event: OrderEvent) -> Result<OrderState, IllegalTransition> {
        match (self, event) {
            (OrderState::New, OrderEvent::Accept) => Ok(OrderState::Accepted),
            // ...
            (from, event) => Err(IllegalTransition { from, event }),
        }
    }

    pub fn name(self) -> &'static str { /* ... */ }
}
```

- [ ] **Step 1: Write the failing tests**

```python
def test_emits_one_variant_per_state(self):
    src = emit_rust_to_string(FSM_TWO_STATES)
    self.assertIn("pub enum OrderState {", src)
    self.assertIn("    New,", src)
    self.assertIn("    Accepted,", src)

def test_emits_a_match_arm_per_transition(self):
    src = emit_rust_to_string(FSM_TWO_STATES)
    self.assertIn("(OrderState::New, OrderEvent::Accept) => Ok(OrderState::Accepted),", src)

def test_illegal_transition_is_an_error_not_a_panic(self):
    src = emit_rust_to_string(FSM_TWO_STATES)
    self.assertIn("Err(IllegalTransition { from, event })", src)
    self.assertNotIn("panic!", src)
    self.assertNotIn("unwrap()", src)

def test_generated_header_names_the_source_schema(self):
    src = emit_rust_to_string(FSM_TWO_STATES)
    self.assertIn("@generated", src)
    self.assertIn("schemas/fsm/order.fsm.yaml", src)

def test_snake_case_conversion(self):
    self.assertEqual(rust_module_name("VenueSessionFsm"), "venue_session_fsm")

def test_pascal_case_conversion(self):
    self.assertEqual(rust_variant_name("PARTIALLY_FILLED"), "PartiallyFilled")

def test_state_names_round_trip_through_name(self):
    src = emit_rust_to_string(FSM_TWO_STATES)
    self.assertIn('OrderState::New => "NEW"', src)
```

The last one matters more than it looks: the conformance journal carries state names as strings, so
Java's `NEW` and Rust's `OrderState::New` have to serialise identically or every corpus case fails
on a cosmetic difference.

#[test]
fn accept_moves_new_to_accepted() {
    assert_eq!(OrderState::New.apply(OrderEvent::Accept), Ok(OrderState::Accepted));

#[test]
fn illegal_transition_returns_error_carrying_context() {
    let err = OrderState::Accepted.apply(OrderEvent::Accept).unwrap_err();
    assert_eq!(err.from, OrderState::Accepted);
    assert_eq!(err.event, OrderEvent::Accept);

fn state_names_match_the_schema_spelling() {

}
